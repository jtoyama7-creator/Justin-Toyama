## Purpose

This folder is the Phase 5 submission area for the FX hedging project. The objective is to convert the completed, market-populated model into a concise executive recommendation supported by the model evidence.

## Required Evidence

- Final populated FX hedging workbook from Phase 4
- Final decision memo
- Strategy comparison and sensitivity evidence
- Explanation of the selected hedge and why alternatives were rejected
- Documentation of assumptions, limitations, or unresolved data issues

## Decision Framework

The memo should address the company's EUR exposure, current market assumptions, no-hedge USD value, forward/money-market/option outcomes, EUR/USD sensitivity, the recommended hedge, trade-offs between certainty/cost/upside, and implementation steps.

## Audit Rule

Do not invent market inputs or model results. Every numerical claim should trace to the final workbook or an explicitly documented market-data source. If a result cannot be reproduced, flag it rather than presenting it as fact.
